## Deskripsi Singkat
Jajalen Pas adalah aplikasi Sistem Informasi Geografis (SIG) berbasis web yang digunakan untuk manajemen jaringan jalan di Kabupaten Pasuruan. Aplikasi ini memungkinkan pengguna untuk memantau kondisi jalan, mengelola aset infrastruktur (jalan, jembatan, area), serta menangani pengaduan masyarakat terkait kerusakan jalan.
